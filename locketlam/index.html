Các Bước Kích Hoạt

  1. Bấm nút Cài Đặt Module ở trên để nạp vào Shadowrocket.
  2. Vào mục Cấu hình ➔ bấm chữ (i) cạnh file cấu hình ➔ Bật Giải mã HTTPS.
  3. Chọn Tạo Chứng chỉ CA mới ➔ Cài đặt chứng chỉ vào iPhone.
  4. Vào Cài đặt máy ➔ Cài đặt chung ➔ Giới thiệu ➔ Cài đặt tin cậy chứng nhận ➔ Bật tin cậy chứng chỉ Shadowrocket.
  5. Bật kết nối VPN trong Shadowrocket, sau đó vuốt tắt hẳn app Locket chạy ngầm và mở lại để tận hưởng Locket Gold VIP!
